Evaluation design

How VoiceArena measures
what matters

VoiceArena uses pairwise preference evaluation — the same methodology proven by Chatbot Arena for LLM evaluation — adapted for audio. A human evaluator listens to two model outputs for the same input and selects the better one. Evaluators are native speakers of the target language, not English-speaking annotators.

Full methodology: voicearena.com/tts-methodology

01
Same input, two models
A single sentence is synthesized by two TTS models. The evaluator does not know which model produced which output.
02
Native-language evaluator listens
A native speaker of the target language — not a general annotator — evaluates both outputs. This surfaces failure modes invisible to non-native listeners.
03
Structured defect tagging
Evaluators tag specific failure types: mispronunciation, robotic voice, irregular pacing, hallucination, missing word, noise. Granular enough to diagnose, not just rank.
04
Written comment (optional)
Evaluators explain what they heard. 49% of votes include a written comment — the primary source for failure pattern analysis.
05
Aggregated into win rates
Wins are counted per language, per content category. Ties excluded from win rate calculations. Results published continuously.
